\subsection*{Must-Fix Before Upload: Replace Remaining \texttt{dinner} Typos}

There are still several occurrences of \texttt{dinner} in the main paper
and supplementary material. These are obvious typographical artifacts and
should be fixed before submission.

\paragraph{Required global replacement.}

Replace all occurrences of:
\begin{verbatim}
dinner
\end{verbatim}

with:
\begin{verbatim}
d_{\mathrm{inner}}
\end{verbatim}

or, in code-style text:
\begin{verbatim}
d_inner
\end{verbatim}

\paragraph{Examples.}

Replace:
\begin{quote}
\texttt{batch=1, dinner=1024, dstate=16}
\end{quote}

with:
\begin{quote}
\texttt{batch=1, d\_inner=1024, dstate=16}
\end{quote}

Replace:
\begin{quote}
\(u \in \mathbb{R}^{B\times \texttt{dinner}\times L}\),
\(\texttt{dinner}=2048\)
\end{quote}

with:
\begin{quote}
\(u \in \mathbb{R}^{B\times d_{\mathrm{inner}}\times L}\),
\(d_{\mathrm{inner}}=2048\).
\end{quote}
